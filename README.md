# TextCompare+

TextCompare+ is a lightweight web-based text comparison tool designed to help users quickly identify differences between two blocks of text. It is useful for reviewing edits, spotting changes in content, and comparing versions of text in a clear and visually structured format.

## Overview

This tool allows you to paste two pieces of text and instantly view the differences between them. Added and removed content is highlighted so the comparison is easy to read and understand.

## Features

- Compare two text inputs side by side
- Highlight differences clearly for quick review
- Display added and removed change counts
- Show a simple visual diff layout for both text blocks
- Ignore capitalization for more flexible matching
- Remove line breaks during comparison when needed
- Provide word and character counts for each input
- Responsive and simple interface for everyday use

## How It Works

1. Enter the original text in the first field.
2. Enter the revised text in the second field.
3. The tool compares the two inputs and highlights the differences.
4. Review the results in the output section and use the available options to refine the comparison.

## Options

- Ignore Capitalization: compares text without being affected by uppercase or lowercase differences.
- Remove Line Breaks: treats line breaks as spaces so the comparison focuses on the content itself.

## Use Cases

- Comparing document revisions
- Reviewing rewritten content
- Checking edits in written text
- Identifying changes between two versions of a paragraph or sentence

## Technologies Used

- HTML
- CSS
- JavaScript
- diff-match-patch library for text comparison

## Getting Started

Open the application in a browser and start comparing text immediately. No complex setup is required.

## Project Notes

This is a front-end tool built for simple and efficient text comparison. It is intended for quick manual review rather than large-scale document processing.
